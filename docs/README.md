## 文档维护约定

- 根目录 README 保持简洁，介绍项目定位、架构概览和文档入口。
- 详细职责与状态归属在架构文档维护；功能范围和进度规划在实施计划维护。
- 协议细节后续设计，明确区分已确定的架构、待确认的设计与已实现的功能。
- 文档使用中文和 Markdown，相互引用使用相对路径；新增文档时更新本导航。
- 架构或范围变化时，同步检查项目介绍、相关设计文档和贡献指南，避免重复定义产生冲突。
